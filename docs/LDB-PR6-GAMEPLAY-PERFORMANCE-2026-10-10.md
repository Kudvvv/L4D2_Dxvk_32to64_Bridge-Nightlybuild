此前 v1.2.1 x64 第二轮 Avg FPS：静止 374、移动 307、开枪 341；同轮原生 DXVK 第二轮：静止 377、移动 310、开枪 363。数据来自既有《LDB v1.2.1 实机对比原始记录》。与本轮测试日期/条件及采样窗口无法做到严格配对，不用于计算本轮性能差异。

## 可由当前材料支持的观察

- 本轮 PR #6 对 v1.2.1 x64 的 Avg FPS 差异分别为：静止 −19.4%、移动 −1.0%、开枪 −3.6%。
- 本轮 v1.2.1 x64 对原生 DXVK 的 Avg FPS 差异分别为：静止 −12.2%、移动 −14.8%、开枪 −16.0%。这部分差距不能归因于 PR #6。
- 1% Low 与 0.1% Low 没有出现三个场景同方向、同幅度的变化。单次截图不能判断低帧表现是否实质改善或恶化。
- 当前只能确认“PR #6 最新构建可以进入本次测试场景并采得数据”；不能据此证明长时间游玩或连续跨地图切换稳定性，也不能证明 IPC 正确性缺陷完全消失。
- 不能把 PR #6 相对原生的全部 FPS 差异认定为 PR #6 的 IPC 代价。

## 后续验证建议（非本轮结果）

采用 v1.2.1 → PR #6 → v1.2.1 → PR #6 的交替测试，优先重测静止场景；统一地图/视角、FPS 上限、DXVK 后端、配置、采样窗口及监控项，并保留逐帧 frametime CSV、构建 ID 和诊断日志。另独立完成连续过图与 x86 Host 回归。

## 统计与证据限制

- 截图只能提供单个时点 OSD 的当前显示与累计统计；没有逐帧样本量、方差、置信区间。
- 画面位置和亮度不同，无法保证严格同场景条件。CPU% 为 OSD 所示，不代表 IPC 单独 CPU 占用。
- `MEM` 和 `RAM` 双列的具体传感器归属尚未核实；保留读数但不解释其物理意义。
- 目前没有证据将观测差异分解到原子操作、命令队列或 DXVK 后端。
