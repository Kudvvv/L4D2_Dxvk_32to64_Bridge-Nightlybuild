# 上游 1.2.2 隔离候选：稳定性与性能评估

隔离候选分支 v1.2 完整同步上游 `de74cd7d5dd546bfd4f03ab451d0565f1fff0107`，正式版完整基准仍为 `cf49175e8a3c6c2fe45c99aec0680b0d1c864d24`。本次是 IPC 稳定性修复，不宣称提高 FPS。现有 v1.1.10 保持 Latest；候选只进行 validation-only 编译和本机一轮对照，评估前不合入 main 或发布。v1.1.13 已按维护者要求撤回，其本地缓冲区绑定引用优化不重新加入。

## 适用与取舍

上游报告修复了地图加载/切换时数据环覆盖、遗漏唤醒、等待或提交失败后继续操作，以及大包在特定回绕位置被错误拒绝的问题。上游在枪店图与训练图间的切换测试通过，但不代表全部地图和长期游玩均已验证。

上游初步截图对照相对其 v1.2.1 出现约 1%～19% 的平均 FPS 下降，另有枪店到训练图加载增加约 20 秒的反馈；1% low 和 0.1% low 尚无一致结论。截图没有统一回放与逐帧采样，不能把范围当成固定损耗，或直接套用到本分支默认 GPLALL + x64 Host。没有进图/切图问题时可以继续使用 v1.1.10。

候选准备阶段尚未收集新的游戏帧率。维护者已授权本机一轮 v1.1.10 / 候选对照，比较 low 帧、平均帧和切图耗时，测试前备份并在结束后恢复安装与配置。旧版手电报告、ThinFlex 用户复测及上游报告各有自己的验证范围，均不能替代本包的游戏实测。一轮测试不能证明长期稳定性；烟花粒子花屏和 Steam Overlay 等问题不属于本次已确认修复范围。

## 合并与兼容

- Git 合并保留上游全部新提交。对 NVIDIA 原始源码分别应用旧上游、本分支旧补丁与新上游补丁，再按源文件处理实际重叠，避免用上游累计补丁覆盖本分支修复。
- 导入数据环布局、协议 3、双向生产/消费与等待流程、完整包规划、失败传播和所有权处理。保留本分支偏色/纹理字节布局、创建失败清理、buffer lock 边界、连续复制、日志名称生命周期、异步普通内存采样及已验证的命令队列差异。
- 默认保持 GPLALL 2.6.8-2 和 x64 Host；x86 Host 与对应后端继续随包。上游本次没有新增或修改默认配置。
- 单一完整 ZIP + SHA256 的发布方式不变。L4N 2.51.0、Starfelll（@Starfelll）归属、用户配置/shader、五份配套模板/QC/VMT、直接安装的 Bridge 菜单插件、ThinFlex DLL 及精简规则全部保留。
- 必须一起更新或回退 `bin/d3d9.dll`、`bin/.l4d2bridge/L4D2Bridge32.exe` 与 `L4D2Bridge64.exe`。不要混用新旧 IPC 协议版本，升级前保留自己的配置与备份。

## 验证要求与发布证据

补丁需通过 NVIDIA `9aa74f8`、`5fd30eae` 与固定构建源 `3a75b814` 应用检查。GitHub Actions 必须完成 x86 Client、x86/x64 Host 和 L4N 插件编译，运行上游数据环契约、API 失败所有权、Device/Module 双向传输（包括回绕、满载、失败及大型上传）与本分支既有原生回归，再执行完整包校验。

构建与相关测试通过后先评估本机对照结果，再决定是否值得合入或发布。具体提交、补丁指纹、Actions 运行及附件 SHA256 记录在验证证据；下载后再核验配套 build ID、PE 架构、68 个安装路径和保留载荷。正常路径微基准属于上游调查工具，不能替代游戏 FPS；本次不追加性能优化或反复游戏测试。
